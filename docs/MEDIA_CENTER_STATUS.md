# 个人媒体中心 0.7.2 阶段说明

媒体组件版本为 0.1.2。本版面向个人使用，建立独立于飞牛影视的馆藏和浏览器播放链路；尚未完整实现 Peach 全部功能，不能据此卸载或移除原有影视服务。

## 本轮使用链路

主导航将“馆藏、人物、个人记录”归为观看入口，“工作台、订阅来源、处理队列”归为采集入口，“媒体维护、设置”保留管理功能。人物、作品和列表支持跨页跳转及刷新恢复指定资源；手机导航分为两行，不挤占横向宽度。

- **人物**：从本地 NFO 建立演员与作品关联；按名字或别名搜索，编辑显示名称、简介与别名，上传/移除本应用保存的头像。资料重扫、服务重启后保留。别名不能抢占其他演员身份，不会自动猜测或合并重名人物。头像仅接受经解码验证的 JPEG/PNG/WebP，限制 3 MiB、4096 像素边长和 400 万像素。
- **作品详情**：收藏、稍后观看之外，提供已看/未看、1–10 分评分、喜欢/不喜欢和加入播放列表。评分是个人标记，不等同于来源网站评分。修改不改写原 NFO。
- **个人记录**：历史按播放会话合并，同一次播放定时保存进度不重复增加条目；支持搜索、分页、选择并删除历史。删除历史不删除文件、不清除续播位置。播放中的会话之后仍可产生历史。
- **播放列表**：创建、改名、说明、添加、上移/下移、分页和移除作品；最多 200 个列表，每个最多 1000 部。删除列表只删除关联，不删除影片；馆藏可按列表浏览。版本冲突不自动覆盖或重试，版本刷新完成前禁用后续修改。
- **状态保护**：开始重看不自动取消已看标记；修正 NFO 身份时迁移评分和列表。合并只填补未设置字段；真正冲突保留目标值和源数据库记录，并在资料检查中提示；身份拆分为多个目标时不猜测迁移方向。

旧版仅保存末次播放进度，因此升级最多补回每个资产一条旧历史，不能恢复不存在的过往会话。手工清理后重启不会重新生成这条历史。历史、人物、列表仍是当前管理员共享的个人资料，不是多用户隔离空间。

## 当前可以使用

- 在“馆藏 → 媒体库管理”添加已有目录，主动点击“扫描馆藏”。添加目录本身不扫描；扫描只读，不启动下载、刮削、改名或删除。
- 从视频同名 NFO、同番号 NFO，或适用的单作品 `movie.nfo` 读取标题、演员、简介、年份、厂牌及标签。不同作品共用目录时不套用共享 NFO；损坏、多番号或身份冲突的资料给出提示。
- 显示封面墙，搜索标题、原始标题、番号、演员、标签、简介和厂牌；点击详情中的演员或标签进行精确筛选，显示并可清除当前搜索条件。媒体库筛选、标题/年份排序、分页、收藏、稍后观看及继续观看入口统一。作品内选择不同版本或分卷；离线文件保留记录。
- “多选管理”可跨页选择最多 100 部作品，预览全部媒体库中的所有视频版本及对应 NFO、海报、字幕。输入“永久删除”后直接删除，不经过回收站；共享/无法确认独占的资料保留，其他文件和目录不递归删除。部分失败会报告已经删除的数量，保留馆藏记录供重新扫描核对，不自动重试。
- 工作台“需要处理的任务”和“处理队列”均提供“清理过期任务”，默认超过 30 天，可选 7 天、1 天或手动不限时间。只归档确认过的异常任务；运行、排队和持有文件恢复锁的任务不允许清理。归档保留去重标识、关联及事件，避免重新下载；可通过“已清理归档”筛选查看，不继续执行。
- 手工修正本应用标题，扫描时不会覆盖人工标题。缺少番号前缀时显示待确认，不凭数字猜测作品。
- 通过原文件 HTTP Range 播放、定位；读取本地 UTF-8 SRT/VTT 字幕。播放器保存进度，暂停/关闭后可续播。
- 收藏、稍后观看和进度持久保存。进度写入采用版本校验；网络结果不确定或其他会话已更新时停止自动重试。
- 原文件未变、只是修正 NFO 身份时转移个人状态；同路径被其他视频替换时建立新资产版本，不继承旧视频进度或收藏，旧版本作为不可用历史保留。
- 保留原来的订阅、下载、JAVSP、翻译、处理队列和媒体维护入口；完善搬运与整理步骤的状态说明及旧任务恢复检查。

仅添加自己明确允许本应用访问的媒体目录。工具箱以 root 运行，馆藏 API 限 fnOS 管理员使用；目录登记是主动授权边界，不意味着对所有路径自动获得了独立的 fnOS 文件授权证明。

## 扫描、挂载和数据安全

扫描完整成功后才在数据库事务中发布结果。取消、读取失败或 SQL 发布失败不把旧馆藏标为全部消失。目录设备号/inode 用于识别挂载变化；路径被另一真实目录占据时拒绝继续读取。

目录迁移、挂载变化或旧测试数据库升级后，可使用“重新关联”显式确认目录。馆藏和个人记录保留，但确认后需要重新扫描才能播放。文件版本指纹使用设备/inode、大小和修改时间，不是完整内容哈希；修改文件属性可能产生新版本。

资产接口只接收登记 ID，不接收任意磁盘路径。根目录受约束，拒绝媒体符号链接、越界海报路径和 NFO 外部实体；海报仅提供受大小限制的本地常见栅格图片。新馆藏写接口还要求 JSON、进程级随机 CSRF token 与来源校验，兼容飞牛网关改写 Host，不信任请求自行提供的转发主机头。

删除使用预览快照与执行前核对，文件发生变化时拒绝操作；持久化文件恢复锁同样阻止删除。为防止并发改名误删，Linux 会短暂将单个目标原子捕获到服务所有的私有目录，确认身份后立即永久删除。这不是回收站或备份。若在此窗口断电/进程退出，可能留下 `.catalog-delete-*` 和 `receipt.json`；后续删除会阻止并在日志给出位置，需人工核对原名和指纹后恢复或完成，不能直接批量清除这些隐藏目录。

本应用的手工标题不会自动改写原 NFO 或强制刷新飞牛影视。暂停/关闭播放器会尝试保存最新进度，正常播放约每 10 秒保存；断电、强制关闭或断网不保证最后一刻的进度落库。

## 明确尚未完成

完整功能目标仍见 [验收范围](MEDIA_CENTER_GOAL.md)。以下能力不能算本版已交付：

- 不兼容编码的转封装、转码、硬件编码探测和转码缓存回收；目前直放取决于浏览器解码能力。
- 创作者、厂牌及系列等完整资料页，自动联网补全演员头像、多来源字段候选与冲突复核、图片编辑及预览时间轴。当前人物页面仅覆盖本地演员及人工资料；冲突源记录尚无可视化合并编辑器。
- 在线字幕搜索、字幕样式/简繁处理、外部播放器与 VR 限时播放链接。
- 偏好分析和推荐；当前反馈只保存个人意图，不会假报已生成推荐。
- 跨站关注、发现/想要、浏览器资料导入、115/CloudDrive2/PikPak 云下载和用户脚本配对。
- 下载整理完成后自动登记到新馆藏、持久化的增量馆藏扫描任务及完整备份恢复界面；本版需要主动扫描。
- 对飞牛官方手机/TV 客户端协议的兼容。桌面与手机浏览器界面不等同于官方客户端兼容。

## 自动化验证

全仓库运行 `npm test`；仅 Go 或前端分别运行 `npm run test:go`、`npm run test:frontend`。馆藏专项：

```bash
cd modules/media
go test -race ./internal/service -run '^TestCatalog' -count=1 -coverpkg=./internal/catalog
npm run build:frontend
CATALOG_PLAYWRIGHT=/absolute/path/to/playwright CATALOG_REPORT_DIR=/absolute/path/to/report \
  go test -tags=catalog_browser ./internal/service -run '^TestCatalogBrowserJourney$' -count=1 -v
```

浏览器测试需要现有 Node.js、Playwright 浏览器及 FFmpeg，不下载或读取用户影片。它生成 9 部作品、10 个文件的中性样本，通过实际 HTTP API 和 SQLite 完成导入、手动扫描、关键词/演员/标签搜索、人物编辑/头像与刷新保留、评分/已看/反馈、有序播放列表、会话历史和选择清理、慢请求期间禁用旧版本操作、版本选择、收藏、稍后观看、标题修正、真实 H.264/AAC 播放、定位、字幕轨道、进度保存/恢复、重新关联、多选永久删除样本、过期任务清理与归档以及桌面/手机布局检查。浏览器控制台不应出现运行异常。

覆盖率只对馆藏核心统计，不能将其等同于整个媒体产品覆盖率。NAS 安装和真实格式验证需要单独记录，不能用合成样本通过替代全功能验收。

### 0.7.2 已核对的证据

- 全仓库 Go race 回归、媒体组件 `go vet`、146 项前端测试和生产构建通过；馆藏核心专项合并覆盖率 80.5%。
- Chromium 桌面 1440×1000、手机 390×844 的上述交互链路通过，无应用控制台错误；另外用延迟响应验证列表刷新期间不会启用旧版本操作。
- 在 x86_64 NAS 上运行隔离测试样本，并用飞牛原生打包工具生成 FPK；安装前检查版本、运行状态及无正在执行的媒体任务。
- 安装后为工具箱 0.7.2 / 媒体组件 0.1.2，五个原启用模块恢复运行。对比安装前后的 14 张既有表：行数和内容摘要全部一致，模块开关与 JAVSP 配置摘要一致；数据库完整性通过，外键检查为零。新表只补建人物索引及旧进度可证明的单条历史，不改写原媒体文件。
- 实机检查仅使用既有索引和只读 API，没有扫描、批量修正、删除真实影片或清理用户任务。没有据此宣称已验证不兼容媒体格式、外部站点、转码和其他尚未完成的能力。

本版仍处于测试阶段。使用者应自行评估风险、管理数据副本；项目按许可证“按现状”提供，不作可用性、数据完整性或适用性保证。不要在尚未验收完整功能时把它当作唯一媒体管理入口。
