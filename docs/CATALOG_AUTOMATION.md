# 整理完成后登记馆藏

工具箱 0.7.6 / 媒体组件 0.1.6 将文件整理与馆藏登记分成两个可恢复阶段。自动登记默认关闭，升级不会扫描目录或自动添加媒体库。

## 设置与使用

1. 在“设置 → 目录与命名”确认 JAVSP 成品目录。
2. 在“馆藏 → 媒体库管理”添加该目录。添加本身不扫描；已有影片仍需手动“扫描馆藏”。
3. 按需要勾选“整理后自动登记馆藏”，点击“保存登记设置”。
4. 之后成功整理的影片会进入同一处理队列的“馆藏登记”阶段。成功后显示作品、文件和媒体库数量，可点击“前往馆藏”。

流程：RSS 发现 → qB 下载 → 完成搬运 → JAVSP 整理 → 馆藏登记。

开启后只登记成功整理任务已确认的输出，不遍历成品库，不把其他离线文件标记为丢失，不修改原视频、NFO 或图片。只有完整、可验证的整理结果才进入登记；部分成功、超时或只有输出路径的任务不算完成。

保存设置只影响之后成功整理的影片，不追溯既有成功任务。关闭开关不会撤回馆藏或取消已排队的登记；后者可在处理队列单独取消。

## 失败与重试

| 情况 | 处理 |
| --- | --- |
| 输出目录未添加为媒体库 | 在媒体库管理添加实际输出目录，再点击“重试馆藏登记”；不需要重新整理或全库扫描。 |
| 输出文件、整理凭据或挂载身份变化 | 先核对文件与挂载，必要时重新关联媒体库。不要把新文件当成旧文件直接重试。 |
| 服务中途停止 | 已确认的整理输出和登记阶段保留；重启接续登记，不重复运行 JAVSP 或搬运。 |
| 登记取消、提交冲突或失败 | 原馆藏与整理结果保留；登记与任务完成在同一个事务提交，不会出现半批登记后报成功。 |
| 设置被其他页面修改 | 保存拒绝旧版本；显式点击“重新读取登记设置”，核对后再保存，不自动覆盖。 |

支持已经登记的文件被整理移动后保留资产 ID、观看进度和个人记录，但仅限原始与目标文件身份、大小、修改时间及原路径消失均能证明同一次移动。硬链接、复制及歧义目标不假装是原资产迁移。同一目标已存在的不同代记录只会按精确路径退休，不清理其他馆藏文件。

## 实现与验证边界

- 复用原 Go 进程、SQLite、影片队列和重启恢复，不增加常驻服务。
- 多文件、多媒体库登记及队列完成原子提交；与全量扫描、媒体库添加和重新关联互斥。
- 输出必须在已登记媒体库内，使用最具体的根目录；根目录身份失效时不回退到上层目录。拒绝越界路径、媒体符号链接、父目录符号链接及不符的文件指纹。
- 手动全库扫描仍是原有同步接口，尚未支持持久暂停/续扫；自动目录监听、云盘 webhook 和定期补扫也未因本功能而完成。
- 浏览器验收使用隔离的中性影片与合成整理器，验证真实移动、同名 NFO、队列、HTTP、SQLite 和页面。该结果不代替外部刮削站点、真实用户影片或其他硬件/浏览器验收。

仍为测试阶段；请保留必要的数据副本。不可恢复删除与任务归档是不同功能，登记失败不应通过删除影片来解决。
