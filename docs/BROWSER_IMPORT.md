# 浏览器资料导入

本页记录工具箱 0.7.5 / 媒体组件 0.1.5 的文件导入能力，已完成 fnOS 1.2.0800 x86_64 上的隔离样本、安装及数据保留验收。完整个人媒体中心目标不因本页缩减；桌面自动采集与真实用户导出格式验收仍另列。

## 使用流程

进入“个人记录 → 浏览器资料”，只选择自己明确愿意导入的文件。NAS 不会自动发现或读取电脑浏览器，服务不会访问导出文件中的网址。

1. 选择创建来源，或明确选择一个已有来源进行更新，填写名称与资料类型。
2. 选择文件，点击“预览导入”，核对有效条数、关联馆藏条数、无效网址与重复记录数。页面仅展示前五条样本；预览不写入来源。
3. 点击“确认导入”。服务重新解析同一文件并核对预览摘要，在事务中发布；解析、校验或保存失败时保留旧资料。
4. 如需参与推荐，在“偏好与推荐”明确开启分析并选择“已导入浏览器资料”。导入本身不改变分析主开关或其他来源。

### 来源操作的区别

| 操作 | 已有资料 | 后续更新 | 推荐贡献 |
| --- | --- | --- | --- |
| 停止读取 | 保留 | 拒绝导入更新，需先恢复 | 已有贡献保留 |
| 恢复读取 | 保留 | 允许明确导入 | 不额外放大贡献 |
| 关闭“参与分析” | 保留 | 不受影响 | 暂停参与计算 |
| 删除来源 | 永久删除该来源的归一化资料 | 旧请求不能复活来源 | 移除该来源贡献 |

历史是增量合并，按归一化 URL 与时间去重；书签是当前快照，成功更新时替换该来源旧书签。同一规范作品的重复访问和重叠来源不会叠加成多份推荐权重。不会将访问记录当作已观看、累计观看时长、购买、收藏或外站关注。

相同类型、相同归一化内容的重复文件不会创建重复来源。不同内容不会仅凭同名自动覆盖；请明确选择来源更新。来源名称冲突、版本变化或被删除时需要重新核对，不自动重试写入。

## 输入格式

| 输入 | 识别依据 |
| --- | --- |
| Chromium 历史数据库 | `urls` / `visits` 的必需列；微秒自 1601 起 |
| Firefox / Zen / PaleMoon 历史 | `moz_places` / `moz_historyvisits`；微秒，Android 毫秒兼容 |
| 旧 Firefox Android 历史 | `history` / `visits` 的 GUID 关联 |
| Safari 历史 | `history_items` / `history_visits`；秒自 2001 起 |
| Qutebrowser 历史 | `History(url,title,atime)` |
| Firefox 书签数据库 | `moz_bookmarks` / `moz_places`，仅网址书签 |
| Chromium Bookmarks JSON | `roots` 下递归网址节点 |
| Firefox JSON 书签备份 | `children`、`uri` 网址节点 |
| Netscape HTML 书签 | 标准 DOCTYPE，网址、锚文本与 ADD_DATE |
| browserexport JSON / JSONL | `url`、数值 Unix 秒 `dt`、可空 `metadata.title` |
| Takeout History JSON | `Browser History` 数组、Unix 微秒 `time_usec` |
| Takeout My Activity HTML | 已支持动作、目标链接、UTC/GMT/HKT 日期 |

支持 gzip、XZ、LZ4、Zstd、ZIP 和 tar.gz。ZIP/tar 只在内存中读取成员，不提取到用户路径；拒绝越界成员、重复成员名及链接。类型依据实际结构和魔数识别，不把文件名或用户填的浏览器名称当作证明。

复制原生数据库前关闭浏览器，或使用能导出完整快照的工具；只复制仍在使用中的主文件可能遗漏 WAL 中未提交到主文件的记录。应用不会擅自打开电脑上的 WAL 或资料目录。

## 隐私与安全边界

- 仅限现有飞牛管理员入口；写入要求同源 JSON、随机 CSRF 与明确确认。
- 上传最多 32 MiB，累计展开读取最多 64 MiB（嵌套和多个成员共同计费），每次最多 50,000 条；归一化 URL/标题/时间累计最多 16 MiB。超限返回失败，不截断后报成功。来源总数最多 100、持久资料总条数最多 200,000。
- 单并发解析，服务解析阶段限时；SQLite 独立私有临时副本、只读 immutable、query-only、trusted-schema 关闭、固定查询、资源限额，不向业务数据库 ATTACH 不可信文件。临时副本在结束后删除。
- HTML 使用流式 Tokenizer、token/缓冲/层级限制，不生成任意 DOM、不执行脚本；JSON 限制嵌套及累计遍历工作量。解压器限制字典/窗口，压缩流必须读至结束并校验。
- 只接受 HTTP(S) 网址，含用户凭据的网址跳过；移除片段和任意查询参数，只保留用于资料定位的 `v`、`id`、`q`。标题和搜索词仍可能包含个人信息，请先检查导出文件。
- 原始上传文件不会持久保存；归一化网址、标题、时间进入私有应用数据库。错误和日志不输出原始浏览记录。页面按纯文本显示，不将导入内容当作 HTML 或可点击外链。
- 只在已知媒体站点及完整、无歧义的番号下关联已有馆藏；冲突、多番号或未知来源保留为未关联资料，不猜测演员、标签或缺失前缀。当前不联网补全，也不把未关联条目伪装成库外发现。
- 删除来源不是安全擦除数据库页、既有备份或磁盘介质；SQLite 逻辑删除后的取证恢复不在承诺范围。不会删除影片或电脑原始导出文件。

## 自动化与实机证据

独立生成的中性样本覆盖全部上述 schema、压缩格式、Takeout 多成员去重、坏时间、坏 SQLite/view/虚拟表、路径越界、重复成员、tar 链接、截断压缩、展开与文本预算、递归 JSON 工作量、HTML token 数、重复导入、事务故障回滚、停止/恢复/删除、旧请求不复活、旧四来源配置迁移与幂等、跨会话版本冲突，以及桌面/手机实际上传链路。

本地解析核心专项覆盖率 85.0%，馆藏核心合并专项 80.5%；仅代表对应专项，不是全产品覆盖率。NAS 中性样本验证真实文件选择、只读预览、重复导入、停止/恢复/删除、可选推荐贡献、409 后显式重选、亮/暗色与手机布局；原有播放、字幕和软件 HLS 链路回归通过。详情见 [阶段说明](MEDIA_CENTER_STATUS.md)。

升级保留了任务、记录、馆藏和 JAVSP 配置：23 张原有表摘要一致，另 1 张配置表只进行预期的默认关闭来源迁移；最终包复装后 26 张表及配置全部一致。安装后的统一入口也验证了中性样本预览不新增来源，未启用真实用户分析。

用户自行选择的真实导出格式仍需验收。桌面自动读取/定时导出配套、浏览搜索词与库外资料补全、全部偏好维度仍未实现，不能将文件导入范围当作完整 Peach 功能已完成。
