# 自动删除重复影片

入口：影片采集任务中心 → 媒体维护。

- 同番号合并比较，例如 `ABC-123.mp4` 和 `ABC-123-C.mp4`。
- 保留体积最大的一份；最大体积相同时按完整路径字典序保留一份。
- 其他较小或同大小视频永久删除。这里按番号和大小判断，不要求内容完全相同，也不判断画质或字幕版本。
- 仅删除视频，不删除同名 NFO、海报等文件。
- 不处理无法可靠识别番号的文件、符号链接、STRM、零字节文件、分段影片组及近期修改的文件。默认要求至少 24 小时未修改。
- 删除前校验目录、候选文件与保留文件身份、大小、修改时间，以及保留文件的可读性和采样指纹。应用内部整理、搬运和维护操作互斥。

「预览保留与删除」不修改文件。「保留最大文件并立即清理」会重新扫描再执行，不直接信任旧预览。

定时区的「自动删除重复视频」和「自动清理空目录」是独立开关，共用每天时间/执行间隔。新安装默认关闭；修改后需保存设置。开启去重不隐式启用空目录删除。

运行记录可展开查看保留路径、删除路径、跳过原因和删除文件的逻辑大小。每类记录最多保留 100 次；逻辑大小不等于 Btrfs 快照或硬链接环境中实际释放的磁盘空间。

管理员 API（相对媒体模块地址）：

- `POST /api/maintenance/duplicates/preview`：预览自动规则。
- `POST /api/maintenance/duplicates/cleanup`：执行自动规则。
- `PUT /api/maintenance/config`：`duplicate_cleanup_enabled` 控制定时去重，其他原有配置字段保持不变。
