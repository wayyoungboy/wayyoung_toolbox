# 无视频残留附件清理

入口：影片采集任务中心 → 媒体维护 → 无视频残留附件清理。

适用于删除视频后留下 NFO、封面、海报、剧照和字幕的成品影片目录。

识别与删除规则：

- 目录内必须有可解析、根节点为 `movie` 的 NFO；维护根目录本身永远不删除。
- 影片目录及所有子目录都不能有视频（包括 ISO、STRM 等）。
- 只允许图片、NFO、字幕及 `.DS_Store` / `Thumbs.db`；未知文件、符号链接、受保护目录或嵌套其他影片 NFO 时跳过。
- `.actors`、`extrafanart`、`extrathumbs`、`subs`、`subtitles` 不会被独立识别为待删影片目录。有视频的影片目录及其附件整体保留。
- 目录和附件均须达到最短未修改时间，默认 24 小时。刚删掉视频的目录会等待这一时间后才符合条件。
- 每次删除前重新核对完整目录清单、文件身份、大小和修改时间；不使用递归强制删除。只逐个删除扫描确认的附件，最后删除空目录。
- 清理不可恢复，不会修改飞牛影视数据库。含未知文件或无有效 NFO 的目录交由人工检查。

先点「预览残留目录」查看范围和附件，再点「清理无视频残留」执行；执行时会重新扫描当前维护目录。运行记录保留处理数量、目录和错误。

「自动清理无视频残留附件」默认关闭，与重复视频清理、空目录清理独立，共用定时执行时间。自动去重刚删除视频留下的目录会先等待保留时间，不会在同一轮立即清掉附件。

管理员 API（相对媒体模块地址）：

- `POST /api/maintenance/orphan-folders/preview`：只读预览。
- `POST /api/maintenance/orphan-folders/cleanup`：永久清理。
- `PUT /api/maintenance/config`：`orphan_cleanup_enabled` 控制定时清理，其余配置字段需要保留。
