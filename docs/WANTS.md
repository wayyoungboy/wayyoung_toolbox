# 想要清单

源码目标为工具箱 0.7.10 / 媒体组件 0.1.10；安装及实机验收进度见[阶段说明](MEDIA_CENTER_STATUS.md)。这是完整 F12 的一个交付切片，不代表演员联网新作订阅已经完成。

## 使用

进入“发现与采集 → 想要清单”，按完整番号手工登记。可填写标题、发行日期、演员和厂牌，按这些字段搜索，或按阶段筛选。资料可留空；不会从缺少前缀的数字猜测作品，也不自动联网补齐。

- **待查找**：尚未入库，明确点击“搜索资源”才进入对应番号的资源页面。跳转本身不查询外站、不下载。候选下载仍须独立确认。
- **未发售**：按填写的发行日和 NAS 当前日历日期计算；此入口暂不提供搜索。没有自动倒计时任务。
- **已放弃**：“暂时放弃”仅暂停清单中的查找意图，可手工恢复；不会取消已有下载。显式放弃优先于未来发行日期，避免用户操作被日期掩盖。
- **已入库**：只有实际文件通过馆藏登记发布，才写入凭据。qB 完成、搬运完成或 JAVSP 整理完成本身不算馆藏入库。已存在可用馆藏的作品不接受重复登记想要。

想要清单不是馆藏的“稍后观看”，不创建没有文件的馆藏作品。重复加入相同番号保留原资料，不覆盖手工快照。编辑仅作用于清单，不修改原视频、NFO 或馆藏资料。

“查看下载任务”跳转到原持久任务，并不承诺任务已经成功。移出想要只删除清单记录，不删除视频、配套资料、观看历史或下载任务。需要停止下载时请在原任务/下载器中单独处理。

## 一致性与失败恢复

新增 `catalog_wants` 表，不重建已有馆藏或个人资料表。持久状态为 `wanted / given_up / acquired`；未发售是派生阶段。最多保留 10000 项，每页 48 项；标题 1000 字符、厂牌 300 字符、演员最多 100 位且每位 200 字符，日期必须是真实的 `YYYY-MM-DD`。

PATCH/DELETE 必须携带当前 `version`。版本变化后返回 409，页面要求重新读取，不自动覆盖或重发。双击、超时、关闭页面及响应丢失均不会触发自动重放；超时只停止等待，不等于事务必然失败。不确定新增使用独立的完整番号等值 GET 核对，不受当前关键字、阶段或页码影响。核对仍无记录时保留原输入供用户再次确认，不自动提交。URL 保留筛选和页码；一次性带入的番号在登记或取消后从 URL 清除。

RSS/显式资源下载生产者在自己的事务中关联 `last_job_id`，不冒充入库证据。同步扫描、后台扫描和精确文件登记只使用已验证并发布的 asset；与清单更新共享事务。整理生产者的成功状态及入库凭据也在同一个事务中，故障不会留下半条成功记录。大库按 200 个 asset 分块查询，不把单次精确登记的 1000 项预算错误套到整库扫描。

凭据保留 asset、work、来源、批次、时间及可选生产者编号。当前匹配必须同时满足 asset/work 身份与登记时的可用状态；GET 不重新读取文件系统。文件不可用或 NFO 改正身份后保留历史凭据，既不自动重置想要，也不重新下载。没有匹配的可用馆藏时，用户可以显式重新加入，清除旧凭据并恢复待找状态；原非空人工资料保留。

## API

以下相对媒体模块入口，均限 fnOS 管理员；写入要求 JSON、同源与 `X-Catalog-CSRF`，会话令牌仍由既有 `/api/catalog/session` 提供。响应 `Cache-Control: no-store`。

| 方法 / 路径 | 用途 |
| --- | --- |
| `GET /api/wants?query=&phase=&limit=48&offset=0` | 本地列表、当前查询范围的阶段计数及分页 |
| `GET /api/wants?code=TEST-001&limit=1&offset=0` | 完整规范番号等值核对，不使用子串查询 |
| `GET /api/wants/{id}` | 最新单项及版本 |
| `POST /api/wants` | `code` 与可选 `title / release_date / studio / actors`；新增 201，重复 200 |
| `PATCH /api/wants/{id}` | `version` 与可选资料或 `state=wanted/given_up`；不能手工伪造 acquired |
| `DELETE /api/wants/{id}` | 仅 `version`，只移出清单 |

未知/重复查询参数、未知/null JSON 字段、无效日期和越界数据均拒绝。客户端不能提交来源 URL、下载路径、job 身份或入库凭据。

## 验证与边界

`wants_test.go` 覆盖只读、权限/CSRF、完整身份、资料保留、版本冲突、16 并发只一次、重启、四种入库路径、写后回滚、历史资产重归属及 1001 个中性视频发布。`wants-browser.mjs` 使用真实 HTTP/SQLite、合成下载器与临时中性文件验证页面、资源选择、原任务关联、入库、冲突、丢响应、筛选、49 项过期页码、URL、手机/深色和移除只影响清单；不连接真实下载器或媒体库。

本轮没有新作来源、已读/忽略 feed、来源补全重试、批次撤销、自动资源搜索或云下载。不能把这些缺口算作完整 Peach 发现能力；来源行为核对和后续范围见[发现与获取契约](MEDIA_DISCOVERY_ACQUISITION.md)。搜索词、演员和想要意图属于个人资料，保存在应用数据库；URL 可能含搜索内容，分享前请检查。文档和测试只使用中性样本，不提交私有配置或实际馆藏信息。
