# 后台馆藏扫描

工具箱 0.7.7 / 媒体组件 0.1.7 将页面扫描接入持久任务。这仍是只读全库清点，不是目录监听或只处理变更文件的增量扫描，不会自动开启整理、下载或采集计划。

## 使用与恢复

在“馆藏 → 媒体库管理”添加已授权目录，再点击“扫描馆藏”。添加本身不扫描。页面显示候选视频、已读取数量、目录条目和当前路径；候选数量仍可能增加，因此不显示总进度百分比。

- 暂停保留遍历检查点；继续从检查点接续。关闭窗口、切换页面和浏览器断开不会取消任务。
- 原先明确提交、未完成的任务在服务重启后恢复为待执行；已暂停的仍暂停。启动空队列不访问媒体目录。
- 取消丢弃本次暂存；失败或取消后“从头重试”会重新遍历。原文件和上次已发布馆藏不因此删除。
- 完整成功后一次更新馆藏。窗口关闭期间完成的任务，重新打开时也会刷新馆藏卡片与扫描时间。
- 页面过期或写入结果不确定时锁定操作，要求重新读取，不自动重放。修改请求使用任务版本号 CAS。

同一媒体库最多一个待执行、运行或暂停任务，全局最多 128 个活动任务。创建时回收最旧终态历史，保留最近 100 条终态；活动任务不被历史回收删除。新完成的终态在下一次创建时参与回收，不是严格的即时 100 条上限。

## 一致性与限制

扫描与本应用的搬运、整理、删除等写入互斥，并尊重尚未完成的文件恢复锁。其他程序仍可能修改目录；这不是文件系统快照。

读取及发布前核对根目录身份、目录清单、视频版本指纹和实际使用的配套资料。NFO 额外校验受大小限制的内容摘要，目录清单可发现恢复目录时间戳后的成员变化。视频不做完整内容哈希，仍使用设备/inode、大小和修改时间，不保证发现刻意恢复全部这些属性的原地改写。

目录或资料变化、读取失败、取消或 SQL 发布失败时，不发布部分结果，不执行错误的“文件消失”清点。应核对后从头重试。缺少目录清单校验信息的旧开发版暂存也拒绝发布，要求显式重试；已发布资料和个人记录保留。

单任务最多 200,000 个已访问条目，保守逻辑暂存预算为 128 MiB，计入目录 frontier、路径、索引和元数据；不是 SQLite/WAL 物理磁盘配额。超过时停止，需缩小扫描范围。最终事务仍需保存受预算约束的完整资产集合，不宣称恒定内存。

符号链接、普通隐藏目录、回收和快照目录不会作为影片读取；空视频不入库。超大或损坏 NFO 可保留视频与文件名资料并提示检查，不凭缺失前缀猜番号。发现 `.catalog-delete-*` 未完成删除凭据时，旧同步和新后台扫描均拒绝完成；请人工核对，不要直接批量删除隐藏凭据来绕过保护。

## API 和实现

写接口要求管理员、JSON、CSRF 和同源校验。只接受已登记媒体库 ID 或任务 ID，不接受临时磁盘路径。

| 接口 | 用途 |
| --- | --- |
| `POST /api/catalog/libraries/{id}/scans`，`{}` | 创建任务，返回 202 与任务位置 |
| `GET /api/catalog/libraries/{id}/scans` | 历史及独立活动任务，避免遗漏较早任务的重试 |
| `GET /api/catalog/scans` | `before_id` 游标，`limit` 为 1–100 |
| `GET /api/catalog/scans/{id}` | 当前状态和版本 |
| `POST /api/catalog/scans/{id}/{action}`，`{"version":n}` | action 为 pause、resume、cancel、retry；版本冲突返回 409 |

Go 进程内 worker 不增加常驻服务或监听端口。短事务保存遍历 frontier 和解析结果；资产发布、离线清点、演员关联、暂存清理和成功状态在同一事务提交。进度不增加生命周期版本；暂停/取消先中断精确版本实例，并等待指令持久化后才释放，避免退出清理抢先改回待执行。

原同步 `POST .../scan` 暂时保留作内部兼容和回归，页面不再依赖长 HTTP 请求。整理后的定点登记仍是队列 `catalog` 阶段，不会被替换成全库扫描。

## 验证范围

TDD 覆盖暂停/重启游标、旧执行器取消、原子发布回滚、目录及 NFO 变更、恢复时间戳、预算、旧表迁移和写入互斥。Linux 还验证不能无损表示为 JSON 的文件名安全拒绝。

真实 HTTP/SQLite 的隔离中性样本验证进度、关闭重开、暂停/继续/取消/重试、409 锁定、完成刷新，并回归播放、字幕及个人资料。视口为 1440×1000 和 390×844。专项覆盖率、FPK 与安装证据见[阶段说明](MEDIA_CENTER_STATUS.md)；不代表真实用户影片、增量监听或 Peach 全部能力已完成。
