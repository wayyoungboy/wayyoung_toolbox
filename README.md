# wayyoung 的飞牛工具箱

一个面向 fnOS 的单进程工具箱。统一总览展示各模块的服务状态、配置缺口和下一步操作，每个模块仍有独立开关与配置，关闭的模块不会启动对应后台任务。

目前包含五个模块：

- 飞牛备份中心：创建、执行和恢复本地备份任务。
- HA500 硬件工具：查看并控制 HA500 相关硬件功能。
- 个人媒体中心（原影片采集任务中心）：馆藏浏览、播放、本地字幕、收藏与观看进度；保留 RSS、下载入库、影片整理和媒体维护。
- 音乐转换中心：批量转换 NCM 等音乐文件。
- 文件完整性检查：以只读方式检查指定目录中的 PDF、图片、音视频、压缩包和常见文档是否可正常解析。

所有模块直接编译进同一个 Go 可执行文件，不会启动模块子进程或额外 Unix Socket。配置按模块隔离，日志由工具箱统一管理。首次安装时所有模块均为关闭状态。

影片从订阅到媒体库的流程、目录规划和失败恢复方法见 [影片采集流程说明](docs/MEDIA_WORKFLOW.md)。

## 使用顺序与权限

1. 用 fnOS 管理员账户打开工具箱，在“总览与配置”中按需启用模块。
2. 点击“检查配置与连接”，按提示补齐配置。“服务运行”只表示模块已启动，不表示目录可写、下载成功或云端备份完成；检查失败会显示“状态未知”，不会自动执行任务。
3. 进入模块完成配置，再预览、手动执行，最后按需要开启定时任务。重新启用模块会恢复原有已开启的计划，请核对执行范围。

| 模块 | 首次使用需要确认 |
| --- | --- |
| 备份 | 在 fnOS 原生目录窗口授权源目录、选择已挂载的目标目录。已有授权可直接重选；没有授权时不能靠输入路径绕过。预览无误后再备份，挂载写入验证不等于云端上传完成。 |
| 影片采集 | 配置下载器连接、RSS、代理与翻译服务；核对下载目录、待整理目录和成品目录，查看工作流中的待处理项后再重试。 |
| 音乐转换 | 配置输入与独立输出目录。默认保留源文件、跳过同名结果；先扫描预览再转换。配置读取失败时禁止用空默认值覆盖原设置。 |
| 文件完整性检查 | 选择允许访问的存储目录和检查模式。只读检查，不修复、覆盖或删除文件。 |
| HA500 硬件 | 确认设备、驱动与风扇通道，验证后再保存策略；未验证的风扇不会自动接管。 |

切换模块会保留当前页面及未保存表单，但这不是自动保存：刷新页面、关闭模块或重启应用前仍需保存。关闭模块会先显示确认窗口；模块停止或重启后旧页面会失效。工具箱整体版本显示在总览，模块原版本标为“组件版本”。

目录选择没有弹窗时，会提供已授权目录选择；若显示权限错误，应检查 fnOS 登录和授权，不需要放宽整个磁盘权限。升级前应停止应用并一致性备份完整私有数据目录（包括数据库及其 WAL/SHM 文件），不要在进程仍运行时直接复制数据库主文件。

## 安装

从 [Releases](https://github.com/wayyoungboy/wayyoung_toolbox/releases) 下载 `wayyoung_toolbox_*_x86_64.fpk`，在 fnOS 应用中心选择手动安装。

应用需要以 root 身份运行，因为 HA500 模块必须访问硬件接口。启用 HA500 模块时还需要输入 `HA500` 确认设备型号。其他模块仍执行各自的路径保护和管理员请求校验。

## 从源码构建

构建环境需要：

- Go 1.25.13
- Node.js 24 和 npm
- fnOS SDK 中的 `fnpack`（仅生成最终 FPK 时需要）

仓库包含所有自研模块和经过修改的第三方源码，不依赖本机其他项目目录：

```bash
npm test
npm run build
```

构建目标为 `dist/wayyoung_toolbox_0.7.6_x86_64.fpk`。FPK 和实机验收记录见阶段说明；没有 `fnpack` 时可以先生成完整的打包目录：

```bash
SKIP_FNPACK=1 npm run build
```

生成结果位于 `dist/stage/wayyoung_toolbox`，可复制到装有 fnOS SDK 的环境后运行 `fnpack build --directory`。

## 仓库结构

```text
cmd/                         工具箱主程序
internal/                    模块调度、统一入口和文件完整性检查
modules/backup/              飞牛备份中心
modules/ha500/               HA500 硬件工具
modules/media/               影片采集任务中心及内嵌 JAVSP
modules/music/               音乐转换中心及内嵌 ncmdump-go
packaging/wayyoung_toolbox/  fnOS 打包配置和生命周期脚本
web/                         工具箱外壳与文件完整性检查界面
```

## 安全与隐私

影片订阅支持只读识别整理完成目录中的已有番号，并在投递前跳过；qB 延迟可见的原投递任务会后台核对，不会盲目重发。使用方法和识别边界见 [已有影片去重与投递确认](docs/COMPLETED_LIBRARY.md)。

项目不包含示例账号、密码、个人目录或预设媒体路径。需要访问的目录、下载服务账号和翻译服务密钥均由用户在自己的 fnOS 中配置，并写入应用私有数据目录。

文件完整性检查只读取文件内容，不修改被检查的文件。发现安全问题请参阅 [SECURITY.md](SECURITY.md)。
